# R11 — native decoder readout with counterfactual physical pairs

R10 establishes computational feasibility for a native-prefix/text-tail reading path: rank8 q/v adapters in upper blocks28–35,409,600 trainable parameters, finite nonzero gradients. Split FP16 hidden max error failed the initial absolute threshold(.125/.1875); relative L2 is .00106/.00131, max logit error .0195/.0156, teacher argmax agreement100% on two public cases. These are feasibility observations, not exact native parity. Keep a split-native step0 baseline throughout training; evaluate zero-adapter versus native again on every downstream sample.

Freeze encoders, lower28 decoder blocks and all backbone weights. Native media-prefix K/V remain unadapted. Adapters affect upper-eight text-tail q/v only. Read/write the same cached native prefix and native M-RoPE text positions in train/inference, with causal text attention and the full media prefix visible. This trains how the native decoder reads evidence, rather than fitting a final-state correction that can ignore the memory.

Use the same independently selected public48 videos. Train/validation/diagnostic remain32/8/8 origins; only31/8/7 have valid paired endpoint questions. Add one annotation-selected question with a different physical label-flip pattern on each eligible training recording, before model fitting. Preserve original questions. This addresses R4's weak training protocol: training had one question per recording, while diagnostic mixed-pattern requirements used two. All four O/A/V/AV media versions retain equal length and no event clipping. Both different question patterns on a recording share the exact same prefix K/V, making a simple padding-version lookup inadequate. The unmodified N version supplies the existing original human-QA answer; do not invent shifted human-QA labels.

Compare matched native-tail adapters: ordinary paired answer SFT on server1 versus paired answer SFT plus a first-divergent-answer-token ranking loss on server2. Candidate descriptions share a literal prefix; at the first different token both continuations have exactly the same causal history. Ranking uses the two correct/foil token logits from a single correct-answer forward. This is supervised training only; inference is ordinary vocabulary decoding, without candidate enumeration, task labels, answer keywords or a fixed modality order. A human-QA auxiliary preserves general behavior.

Lock before fitting: seed20261020;AdamW lr.0001,wd.01;200 updates;each update one random training recording's four versions with questions sampled uniformly, plus one unmodified human QA. Loss ordinary=mean answer token NLL; ranked branch adds .5 softplus(foil_logit−gold_logit) at the first divergent token. Both use the same examples/order/initialization and total200 optimizer steps. Checkpoints0/25/50/100/200. Select lowest validation recording-averaged first-divergence binary NLL, subject to human-QA token NLL no worse than split-native+0.15. Step0 is always eligible. Report raw choice, strict all-versions and mixed-pattern per-recording metrics; binary-choice accuracy is not generated-answer accuracy. Measure actual option-free generation and the original benchmark MC separately after selection. No benchmark labels select weights, loss, alpha or layers.

This is a proper decoder-adaptation baseline, not enough novelty for a paper by itself. Its training data are still tiny, event labels coarse, and actual inference implicit/narrated-event queries differ from explicit first-onset training. If it fails, inspect gradients/data/causal-use diagnostics; do not call all native temporal information impossible. If it succeeds, compare matched SFT before attributing gains to counterfactual training and test fresh recordings/modalities/contexts. TRACE, SyncRA, TimeLens2, IIT and supervised LoRA constrain novelty claims.
