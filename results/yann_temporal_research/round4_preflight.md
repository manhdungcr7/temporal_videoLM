# R4 — binding-dependent temporal residual with physical paired supervision

Motivation from R3: validation NLL drops similarly with/without time; both select step50, diagnostic localization3/16. Micro8 both5/8, rescue2054/harm1449; address shuffle and zero content bank retain identical MC predictions. This weakens the claim that R3 gains depend on temporal binding. Generated outputs also contain invalid huge timestamps. Do not promote R3 to QA40 as a successful method.

Hypothesis: generic final-state residual training permits a context-only shortcut, while localization/token objectives do not require answers to track temporal evidence. Test an architecture with an exact null-temporal-path identity, trained/evaluated on physical O/A/V/AV interventions with independently annotated endpoint labels.

Data: same independently selected public48 videos. For each eligible video, choose two distinct human action/sound labels and their first annotated instances, with unambiguous onset order in all variants. Prefer four modality directions; record fallbacks/skips before model outcomes. Questions ask which event starts first and answers are the event descriptions, not benchmark Past/Present/Future classes. Pair selection is annotation-driven training/diagnostic construction, not gold-dependent inference on SVHalluc.

Transform actual sampled video frames and audio waveform before their native encoders: delay0 or delta in each modality; pad the other end with black frames/zero waveform. All O/A/V/AV variants have the same extended duration/frame count/audio length, no event clipping, <=45s. AV preserves relative onset ordering; A or V may change it according to annotations. No cyclic roll, waveform reversal, coordinate-only edit, version label or forced semantic synchrony. Different target text lengths can change total teacher-forced token count; require equal input-prompt length separately in audit, not equal total lengths.

Architecture idea (not yet run): content/source attention p_r reads media memory. Let M_c be content summaries and M_t be time-value summaries with global-bank mean removed. Correct final hidden state using bounded W_out[GELU(ctx+mem(M_c+M_t))−GELU(ctx+mem(M_c))]. Zero M_t implies zero correction for any learned parameters. Uniform attention over the full bank makes M_t≈0 numerically. This is a module identity, not a proof of correct semantic evidence, calibrated absence or language-prior removal. Uniform within only one modality need not vanish; test that limitation. Centering per-modality would erase useful relative clock offsets for linear time features and is deliberately not used.

Matched control is the same parameterized model with ordinary single-path residual on the same temporal values and exactly the same paired training data. Use role-specific endpoint grounding for paired examples, plus original human QA/grounding to monitor generic behavior. Both use frozen Qwen3B/vocabulary weights and the same selected-data budget; no micro8 or QA40 checkpoint selection.

Final training specification before outcomes: seed20261017;400steps;AdamW lr.0008,weight_decay.01;per step all4 variants of one random train recording plus one original human QA. Binding loss=correct-answer token NLL + .5*two-description ranking loss +1.0*endpoint grounding. Numeric localization token targets from R3 are not used; ground endpoints directly. Teacher-forced endpoint attention decays linearly to0 by step100, training only. Every other step uses O native context/query while reading source-variant memory; match candidate-prefix hidden states by the actual answer text. This is a labeled representation-interchange auxiliary, distinct from ordinary inference, and related to IIT rather than a newly invented causal-abstraction principle. Both compared architectures receive exactly this training. Checkpoints0/50/100/200/400 selected by validation mean two-description binary NLL +.25*human-QA token NLL. Oracle attention and address shuffling are diagnostic only, never deployable candidate gains.

Ontology correction v2: exclude Muted as an audible endpoint. Keep original selected48 videos; retain valid old pairs, and use annotated valid same-modal fallbacks or record skips where sound endpoints are unavailable. Old ill-posed cases/logs remain in binding48; only binding48_v2 is used for training. Source annotation strings such as Human:other remain coarse and limit semantic conclusions. Native actual sample cadence is not exactly2fps: quantify delay by an even number of sampled frames, then match audio delay to the nearest16kHz sample. Retain original waveform and frame arrays bitwise inside zero/black padding. Restore visual tuple support to the native2/fps tubelet width before training/evaluation, preserving old support metadata for audit.

The main comparison changes both global time centering and the contrast path, so it tests the full design, not isolated attribution to either part. If promising, run the two missing2x2 controls with identical budgets. Full-bank uniform attention is a near-zero correction contract; uniform attention confined to one modality can still change output. That limitation is measured in tam_binding_unit_checks.json and cannot be called calibrated evidence presence.

Informativeness amendment before any R4 fitting: original random endpoint pairs often retain their answer under all4 shifts. Add annotation-selected close cross-source pairs for validation/diagnostic recordings, retaining original questions as controls; no training recordings or benchmark40 samples change. A padding-offset shortcut can succeed on close-pair AllFour alone: A implies visual earlier and V implies audio earlier. Therefore evaluate both original and added questions jointly per recording, especially recordings with different flip patterns across the two questions. Report joint All8 where two distinct questions exist, All4 otherwise, number of independent recordings, and mixed-pattern joint success. Selection uses recording-averaged binary NLL across both questions plus.25*human-QA NLL. Multiple questions/versions are not independent recordings. This amendment is annotation-only and fixed before model outcomes.

Further mathematical caution: forcing uniform attention to give no correction is not a general definition of missing evidence. A real event can occupy the whole clip and legitimately have a flat temporal field; duration and multiplicity can be lost by normalized pooling. Thus R4 is an order/binding readout diagnostic, not the final universal memory proposal. A subsequent measure-based variant should preserve occupancy mass and boundaries instead of treating flatness as absence; test rather than assume that change improves QA.

Core metrics: strict all4 event-order choice correctness per recording, single-stream label-following, endpoint retrieval, original human QA loss, and later ordinary micro8/QA40. A model that improves NLL but cannot beat address shuffling/oracle-memory diagnostics does not demonstrate temporal binding. No claims of novelty or CVPR acceptance from this prototype. IIT/causal abstraction and SyncRA swap diagnostics are related prior art; physical supervision and a residual identity alone are insufficient novelty.
