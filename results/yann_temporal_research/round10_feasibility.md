# R10 — native upper-decoder adaptation feasibility, before claiming a new method

R5 shows a reader can learn with known endpoints, R8 shows media features retain category-localization information, but R6/R7 still fail to connect arbitrary question states to correct evidence. Rather than conclude all native information is missing or endlessly add final-hidden vectors, test whether a native decoder-trained reading path is feasible on2T4.

First a parity/gradient check on one public human-QA recording/server. Extract unmodified native media-prefix K/V at layers28–35 and postblock27 tail states. Replay only causal text-tail queries in the upper eight blocks, concatenating unchanged native media K/V with the current text K/V. Native M-RoPE tail positions and full visible prefix are retained. Before any learning require hidden max error<.02 and vocabulary-logit max error<.25; numerical partitioning can alter fp16 GEMM rounding, so this is bounded parity, not bitwise identity. Then zero-initialize rank8 q/v LoRA hooks on these text-tail forwards and check a finite nonzero human-answer gradient, no backbone mutations, and memory use. Remove hooks in finally.

This is a decoder-adaptation baseline/feasibility check, not novelty or an accuracy result. A subsequent training experiment would need a fixed data/loss/selection recipe and a native-prefix inference implementation that matches this text-only adaptation path. Applying the same LoRA to the media prefix at deployment would change the intended method and invalidate cached native-prefix training.

Initial parity failed the preregistered absolute hidden threshold on both recordings: max hidden error .125/.1875, while maximum vocabulary-logit errors were .01953125/.015625. Preserve that failure. A separately named audit extension reports relative hidden L2, mean absolute error, teacher-token argmax agreement, native/split answer NLL and gradient feasibility without relabeling the original criterion as passed. No candidate accuracy gain or training result follows from this numerical audit.
