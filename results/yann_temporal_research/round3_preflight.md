# R3 — learn a temporal memory readout, not another hand gate

Status: prototype preparation. This is not a validated method and not a novelty claim.

R1 topology-only and R2 question-feedback-only failed to rescue any micro8 answer. Together with historical self-reconstruction/latent nudges, this motivates an answer-supervised readout. It does not prove training is necessary for all future methods.

Independent public Perception Test official training data: prefilter8–45s audio/video, non-cup videos, raw video<=12MB, action+sound+MC annotations available, no invalid na choices. Seed20261016 chooses48 of1001 eligible videos; fixed32 train/8 validation/8 diagnostic. Data is filmed independently of the YouTube-origin SVHalluc clips; identifiers are disjoint, but do not claim a full perceptual dedup audit or participant-disjoint split. Public annotations are human-generated, but action/sound labels are coarse and can still be ambiguous. No validation/test corpus is used for fitting. The research40 remains repeatedly viewed development data.

Prepare3 cases/video: one random human QA converted to answer text without MC choices, one multi-instance visual localization and one multi-instance audio localization from human intervals. No caption-generated event truth, no exact-single-start penalty. Localizations use templated labels from annotation, so this preliminary data does not establish free-form question breadth. No absence supervision yet: do not claim calibrated null or absence capabilities.

TAM-Lite caches a common native block18 media/query representation and final teacher-forced hidden states. A four-role content/source attention reads0.5s media tuples. Retrieval keys exclude the added address features, which instead enter the values. A small learned residual maps memory plus native final state into the frozen vocabulary head. This avoids declaring an untrained latent direction semantic. It is a cheap frozen-readout diagnostic, not the full intermediate-decoder TAM architecture proposed previously. It does not preserve an arbitrary joint distribution exactly.

Matched conditions: same source data, seed, architecture, optimizer and budget; explicit temporal addresses versus address features zeroed. This shares architecture but the zeroed branch has fewer effectively active temporal parameters; report that limitation. Native is an additional reference. Need validation localization and answer metrics, not only changed logits. Train/validation features must use the same hook and last-question-token convention as inference, excluding options.

Before transfer evaluation, freeze training recipe/selection criterion using only public train/validation. Query convention is the last token of the option-free prompt, including the same direct-answer instruction/chat prefix, at block18. MC evaluation requires an option-free native prepass for memory/query, then its unchanged MC readout prompt; generated QA uses its option-free prefill. Check zero-init identity, tuple-permutation invariance, finite gradients, unchanged backbone versions and hook removal. QA40 labels never enter training or checkpoint selection. If memory is ignored, or an address-shuffled diagnostic performs similarly, report a null result and investigate rather than claiming novelty.

Preparation correction: server1 encountered a multi-instance target of102 tokens, exceeding an unnecessary100-token guard. Raise that guard to768 without truncating intervals, changing sample selection, targets, or completed caches. Preserve the original preparation error and resume the same frozen cases. Clip-duration constraints remain unchanged. This is an engineering correction, not a new method/score.

Closest precedents: LatentOmni (sensory latent supervision), SyncRA (intermediate correspondence+answer training), GroundFormer (question-conditioned grounding), temporal-equivariance training, TGB (grounding bridge). A memory/adapter by itself is insufficient novelty. A credible next contribution would need controlled evidence that preserving content–time–source binding improves multiple AV reasoning forms and transfer under independent physical transformations.
