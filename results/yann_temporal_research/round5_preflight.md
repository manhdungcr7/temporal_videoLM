# R5 — privileged oracle-trained readout diagnostic

R4 learned endpoint retrieval is weak (diagnostic role0 1/48 for the full module), but replacing retrieval at inference barely helps (27→28/48). This does not establish that the readout cannot learn from correct evidence: it was trained mostly on its own noisy retrieval. R4's checkpoint selection also improved mainly human-QA token NLL, while binary temporal NLL remained worse than step0.

Before engineering another retriever, train an oracle-only readout diagnostic. Both servers instantiate the same ordinary TAMBindingProbe, no time-centering or contrast path; 800 updates, seed20261017, AdamW .0008, same31 training recordings, same validation/diagnostic groups. Always use human-overlap endpoint attention for roles0/1 and fixed uniform attention for unused roles2/3. Every source-variant memory is read with O native question/answer-prefix context, choosing the correct/other continuation hidden state by answer text. Loss is binary event-description NLL + .05 correct-description token NLL, averaged over four physical variants. Selection uses recording-averaged validation binary NLL only, includes step0. Server1 retains addresses, server2 applies the same deterministic address-permutation corruption used in R4. Both have identical capacity/budget, neither trains the backbone.

This is privileged-input, synthetic-question mechanism diagnosis, not deployable inference or QA40 improvement. Fixed O context makes the physical source memory necessary for label changes, but transformed content can itself retain position/padding information; address-shuffled memory is not guaranteed to remove every time cue. Oracle attention is annotation-dependent. The head may still exploit answer-language biases; report strict all-four and mixed-pattern per-recording metrics. No score from this oracle branch is a candidate gain.

Geometry audit on all stored questions (including duplicate original/extra questions, unlike fit-time deduplication) finds diagnostic exact-event-center order51/56 versus start-order truth and oracle earliest-cell support56/56. Thus onset-sensitive features could matter, but center mismatch alone cannot explain R4's large error and does not prove the full Fourier representation lacks onset information. We do not promote a boundary-memory claim on this observation alone.
