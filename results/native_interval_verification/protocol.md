# Native interval verification diagnostic, 2026-10-17

Goal: test the missing premise of a frozen event verifier before building another latent/grounding method. Human action/sound interval annotations from the previously frozen Perception48 pool supply labels, independently of native predictions and SVHalluc QA gold. Use all16 internal validation/diagnostic origins; these were already used for development and are not a fresh test. No training, coefficient search, QA40/reserve400 access, or task/answer-specific inference rules.

Freeze one eligible label per source modality per origin with deterministic seeds. Keep all occurrences in union/exclusion. Positive2s window is centered on the longest instance (>=.25s union support); negative2s is selected on a.25s grid with no overlap with any instance and a.15s guard. Log every ineligible origin/modality without substitution. This deliberately favors labels with separable temporal support, not a representative sample of all events. Negative means no annotation overlap; it is not separately human-verified absence.

Crop both intervals from original MP4 using the same FFmpeg decoding/encoding recipe. Verify decoded durations and timestamps; native Omni processor retains its sampling policy with fixed96*28*28 max pixels/frame. Evaluate each crop in fullAV, source-only and opposite-only modes. Opposite-only is an evidence-removal control, not an ordinary fully observed accuracy condition.

Scores: (1) native final logits Yes/No log odds for a generic presence question, (2) mean teacher-forced log likelihood of the event description under a generic description prompt, (3) descriptive diagnostic of mean source-media post-L22 logit-lens affinity to frozen input embeddings. The last is a new explicit simple pooled-lens comparator, not an exact reproduction of v8 patch selection. Save raw odds, target token logprobs, model argmax, token/media counts, crop hashes and all metadata. No answer labels are included in prompts. Prefix hidden states from a presence query can be used for lens pooling because media prefix precedes query under the native causal mask.

Primary metric: within-pair positive score > negative score, report ties and binomial sign test; also positiveYes/negativeNo pair accuracy for source-present modes at the fixed native log-odds threshold0. Report modalities/splits separately. ConstantYes, constantNo and random-ranking reference levels are explicit. Conditional description prior cancels in paired differences because target text is identical. Do not call proxy-negative FPR a calibrated deployment absence rate.

Decision: if source-present ranking is weak or opposite-only preserves its advantage, reject the premise that naive native self-verification already supplies trustworthy event grounding. If one score is promising, require independent-origin and repeated-instance validation plus a causal downstream QA test; no novelty or CVPR claim from this diagnostic.

Sources: [official Perception Test annotations](https://github.com/google-deepmind/perception_test), [dataset paper](https://arxiv.org/abs/2305.13786). The official dense intervals are supervision, not a release-wide independent validation of every negative crop generated here.
